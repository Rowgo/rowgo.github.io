About

Hi my name's Rogan, some people say I'm a goofy guy, but I assure you I am very serious.

When I was growing up my three brothers and I would play a lot of multiplayer games. Because there were four of us it meant we usually played with a full party, but when there wasn't enough of us to ruin friendships, one or two of us would play while the others watched. This was where I found my interest in Game Design. To pursue a career in games I went to Vancouver Film School and graduated from their game design program. There, I learned to use game engines such as Unreal Engine(UE) and Unity to create levels, work with assets, and script gameplay using UE blueprints and C#. I also learned to 3D model using Maya, program shaders using Unity shader graph, and how to plan a project from start to finish. After I graduated, I got a job at Byte Camp teaching kids how to make games using Godot, to make ends meet. Since then, I've also learned to write code using c++, and I've learned how to program using HTML, CSS, and Javascript to create this website.

Currently, I'm learning to make online multiplayer games in Unreal Engine with C++ and blueprints. You can check out my current project here.
