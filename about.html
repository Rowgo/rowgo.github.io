About

When I was a kid my three brothers and I would play a lot of multiplayer games since there was four of us, but when their weren't enough of us to ruin friendships, one or two of us would play while some of us watched. This was where I found my interest in game design. To pursue a career in games I went to Vancouver Film School and graduated from their game design program. There I learned to use game engines such as Unreal Engine(UE) and Unity to create levels, work with assets, and script gameplay using UE blueprints and C#. I also learned to 3D model using Maya, program shaders using Unity shader graph, and how to plan a project from start to finish. After I graduated, to make ends meet, I got a job teaching kids how to make games using Godot. Since then I've also learned to write code using c++, and I've learned how to program using HTML, CSS, and Javascript to create this website.
