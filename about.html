About

When I was a kid I would play video games in the basement of my parents house with my three brothers. Sometimes all four of us would play multiplayer games, and sometimes a few of us would play while the others watched. During that time I discovered what I wanted to be growing up.
To pursue a career in games I went to Vancouver Film School and graduated from their game design program. There I learned to design levels in Unreal Engine(UE) and Unity, create scripts using UE blueprints and C#, 3D model using Maya, program shaders using Unity shader graph, and how to plan a project from start to finish.
To make ends meet after I graduated I got a job teaching kids how to make games using Godot, how to 3D model using blender and how to create vector art using inkscape. Since then I've also learned to write code using c++, I've learned HTML, CSS, and Javascript to program this website.
Currently I'm learning to make online multiplayer games in Unreal Engine using C++.
